二、VJ 五阶段处理管线（5-pass Pipeline）

Pass 1色差+噪点→
Pass 2扫描线+调色→
Pass 3边缘描线→
Pass 4生成层合成→
Pass 5音频混音
Pass处理内容核心滤镜 / 参数
1RGB 色差分离 + 细颗粒噪点chromashift（RGB_SHIFT=3）、noise（alls=12）
2扫描线 + 色彩增强 + 暗角geq（每 4px 行暗 8%）、eq（saturation=1.35）、vignette
3低透明度边缘描线edgedetect + blend=overlay:0.12
4生成式叠加层合成NumPy 叠加层视频 blend=overlay:0.15
5金属 BGM + 源音轨混音amix，H.264 / yuv420p 输出
设计原则：VJ 效果定位为"氛围增强层"而非"覆盖层"——所有叠加透明度均压制在 0.15 以下，原始画面内容始终清晰可辨。该原则来自创作中的迭代教训：早期版本曾因 edgedetect 全屏 screen 叠加导致色彩与形体双双丢失，最终回归克制的美学判断。

三、生成式叠加层引擎（vj_engine.py）

使用 NumPy 向量化计算生成 770 帧叠加层，五层生成系统：流场粒子（300 粒子，Perlin 风格流场）、音频波形可视化、几何网格（透视投影旋转）、数据流字符列（七罪主题色上浮）、随机 glitch 块。1280×720 全分辨率下渲染耗时约 12 秒，全部参数（粒子数/密度/速度/色相）以常量暴露于脚本头部，可直接复用与再创作。

四、金属质感 BGM 合成

BGM 由 Python/NumPy 全流程程序化合成（非采样拼接），共 10 层：低频 drone、和声 pad、底鼓/军鼓/踩镲（ADSR 包络）、贝斯、主奏 lead、riser，以及金属质感层。金属音色通过三项技术实现：

技术参数听感
FM 频率调制合成mod_ratio=3.5, mod_index=10非谐波泛音，工业撞击感
Ring Modulation载波 × 45Hz–120Hz钟磬般的金属共振
非谐振分音比1 : 2.76 : 5.40 : 8.93 : 13.34模拟金属板物理振动谱（Stretch Factor 类钟琴声学）

全曲 D 小调，128 BPM，动态分层：段落间由 kick 密度与 riser 长度驱动情绪曲线。

五、实时 VJ 混合器（vj-mixer.html）

纯前端实现（零依赖，单文件）的实时 VJ 控制台，基于 HTML5 Canvas 像素级处理：RGB shift、scanlines、glitch 位移、noise、posterize、feedback 拖影、粒子系统、几何网格、波形可视化等效果模块，支持视频文件加载（本地 File API）、键盘快捷控制（SPACE/1-7/R）、实时参数调节与 WebM 录制导出（MediaRecorder）。展览现场可由表演者实时操控，实现"演奏影像"的现场 VJ 表演形态。

六、作品网站与数字展览架构

作品以单页滚动式网站作为档案载体：Hero 粒子动画 → 申报信息层（作品元数据）→ 七罪交互图鉴（点击展开全屏视频）→ VJ 成片播放 → 展览方案 → 创作流程时间线（含各阶段人工决策点）→ 工程文件 → 申报材料包。网站为纯静态部署（HTML/CSS/JS），无后端依赖，可直接迁移至任何展览服务器或离线展机。
