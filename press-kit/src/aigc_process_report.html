AIGC 创作过程说明 / AIGC Process Report

本作品为 AIGC 深度参与创作的新媒体影像作品。以下完整披露人机协作过程：创作意图（Prompt 设计策略）、人工判断（候选筛选与决策点）、以及后期处理中的人类作者性，以回应"AIGC 作品应考察创作意图、人机协作过程与人工判断有效性"的评审要求。

一、创作方法论：意图先行，机器执行，人工裁决

创作流程遵循"概念 → 分镜 → 关键帧 → 视频 → 人工策展 → 算法后期"六步链路。AI 在其中承担"执行放大器"角色：每一个视觉决策（构图母题、色彩系统、情绪节奏）均由人工在 Prompt 层面定义，AI 负责生成候选，人类负责筛选、否决与重组。作品的主题、叙事结构、美学方向、后期参数全部由人类作者决定。

Prompt 设计遵循三条人工原则：① 每罪一个可被镜头语言捕捉的身体性母题（吞噬/抓取/躺卧/拥抱/伫立/触碰/怒吼）；② 色彩系统互斥，保证七段在剪辑中可被瞬间识别；③ 全部锚定"cyberpunk + cinematic"统一美学基调，避免风格漂移。

三、人工决策点时间线（人工判断）

Phase 1 · 分镜策划 — 人工撰写 3 分钟完整分镜脚本（含每段旁白文案与视觉关键词），确立"片头 18s + 七段各 22s + 片尾 18s"结构。此阶段无 AI 参与。
Phase 2 · 关键帧生成 — 将视觉关键词提交 HY-Image-V3.0 文生图，从多轮候选中按"母题可读性 / 色彩系统吻合度 / 电影感构图"三项标准人工筛选出 7 张定稿，未采用任何一次性生成结果。
Phase 3 · 视频生成 — 以定稿关键帧为输入进行图生视频（非随机文生视频，保证与已确认的构图/色彩一致），人工审核运动方向与情绪节奏后采纳。
Phase 4 · 剪辑策展 — 人工决定七段排列顺序、时长分配与字幕文案；因长视频字幕渲染内存溢出，人工将 drawtext 方案改为 SRT/libass 方案——技术故障的解决本身构成创作决策。
Phase 5 · BGM 合成 — 人工确定 D 小调/128 BPM/金属质感方向，人工设计 10 层合成器架构与 FM/环调/非谐分音参数；AI 仅参与代码纠错。
Phase 6 · VJ 后期 — 本作品最关键的人工判断案例：初版 VJ 管线效果过重（饱和度砍半 + 边缘检测全屏叠加），导致色彩丢失、形体不可辨；第二版色彩恢复但生成层仍盖住画面。创作者基于"效果必须服务于原片叙事"的美学判断，连续两次否决自己的参数方案，最终将全部叠加透明度压至 0.15 以下、移除 glitch 行位移与反馈拖影，确立"VJ 效果是氛围层而非覆盖层"的原则并回写进管线文档。
Phase 7 · 交互系统 — 人工设计 VJ 混合器的模块划分、参数范围与交互逻辑（键盘映射/录制导出），供展览现场实时演奏。
